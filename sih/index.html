🛑 EMERGENCY BRAKING WARNING (EEBL PROTOCOL)
SAFETY PROTOCOL

The Problem with Human Reaction Times

When a lead car brakes violently, trailing drivers experience a 1.2 to 1.8 second delay in seeing taillights, processing danger, and depressing their pedal. On high-speed motorways, this leads to fatal multi-car chain collisions.

The V2V Rescue Link Solution

V01 transmits an EEBL packet in <3 milliseconds via Bluetooth 5.4 / Wi-Fi Direct directly to V02, V03, and V04. The trailing cars' dashboards sound audio alarms and pre-charge braking calipers before the human eye even registers the physical brake lights!

🔌 PHYSICAL HARDWARE IMPLEMENTATION (BILL OF MATERIALS)
PROTOTYPE HARDWARE DESIGN

Web Prototype vs Real Hardware Implementation

This browser application represents the Interactive Web Prototype Simulation of our system. In a production vehicle deployment, the algorithms run on dedicated embedded microcontrollers connected to the car's 12V OBD-II / CAN-Bus system.

ESP32-S3 Dual-Core MCU CORE PROCESSOR

240MHz Xtensa with native 2.4GHz Wi-Fi (802.11 b/g/n) and Bluetooth 5 (LE / Mesh / Coded PHY). Runs the ad-hoc mesh protocol stack.

u-blox NEO-8M GPS Module POSITIONING

10Hz refresh rate with concurrent GNSS reception (GPS, GLONASS, Galileo) for accurate vehicle velocity, heading, and coordinate fixing.

MPU-6050 6-Axis IMU CRASH SENSOR

Triple-axis accelerometer + gyroscope detecting sudden deceleration (>0.6g) for emergency braking and rollovers/impacts.

MCP2515 CAN-Bus Controller VEHICLE BUS

Intersects OBD-II diagnostics port to read real-time wheel speeds, steering angle, ABS trigger state, and brake pedal depression.

Piezo Buzzer & OLED HUD COCKPIT UI

85dB acoustic warning alarm and 1.3" I2C OLED dashboard display delivering driver alerts within 15 milliseconds of packet arrival.

12V to 5V DC Buck Regulator POWER UNIT

Automotive transient voltage suppression protecting the microcontroller from car alternator voltage spikes (load dump protection).

📱 HARDWARE / BACKGROUND MODE – FUTURE IMPLEMENTATION
ENGINEERING CLARIFICATION

Technical Note on Browser Security & Mobile OS Policies: Standard mobile web browsers (Safari, Chrome) pause JavaScript execution when the smartphone screen is locked or turned off to save battery.

For commercial automotive reliability, V2V Rescue Link operates through a dedicated vehicle On-Board Unit (OBU) powered by the vehicle's 12V battery, or as a native Android/iOS background BLE peripheral service with wake-on-packet capability. This ensures emergency warnings are transmitted and received 24/7—even when the driver's phone is switched off.

ℹ️ ABOUT THE PROJECT
COLLEGE / HACKATHON INNOVATION ENTRY

PROJECT NAME & TAGLINE

V2V RESCUE LINK

“Smart Vehicles. Direct Communication. Safer Roads.”

THE PROBLEM

Vehicles lose cellular and GPS connectivity during natural disasters, mountain landslides, remote highway travel, and power grid failures. When a sudden crash happens around a blind curve, trailing cars have zero advance warning, triggering deadly pileups.

THE SOLUTION

Enable nearby vehicles to exchange safety information directly using peer-to-peer wireless technologies (Wi-Fi Direct, Wi-Fi Aware NAN, and Bluetooth 5.4 Mesh) without depending on cellular towers, mobile data plans, or cloud servers.

THE ULTIMATE GOAL

Provide a resilient, decentralized safety communication shield that helps vehicles warn each other about sudden braking, accidents, roadblocks, and environmental disasters in under 15 milliseconds.
